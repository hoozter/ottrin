## Window and state gates

Verify main window, Settings, theme editor, Quick Inspector, the Details sidebar, creation/rename/delete dialogs, About, menus, popovers, tooltips, and already-open/new windows. Exercise normal, hover, active, focus, selection, disabled, warning and error states. Confirm dimensions and text at realistic sizes and scaling. The unreachable legacy Properties popup (no opening action or visible-state setter) was removed; Details is the actual metadata interface. Native root/Settings/editor/Inspector frames share edited window border and rounded corners at 150%; Rename/Create Folder/Delete/About and main/context/More menus were rendered with deliberately distinct panel, input, heading and button roles. Rename panel/input pixels match their own roles; dialog frames now use panel fill, shared window radius and shared window border. Receipts: shared-native-window-roles-running-check.json and dialog-roles-running-check.json. Accent/link inks and all twelve code-subtype blends now pass the expanded 8,708 readability checks across all fourteen preset/mode combinations. The compact picker is rendered and inspected at 100% and 150% native scaling; running RGB, hue, saturation/brightness and opacity edits preserve all unrelated properties, save/reopen correctly and reset to base. Zero opacity preserves RGB and hides the hover overlay; restoring opacity changes only the hovered row. Receipt: compact-picker-controls-running-check.json. Additional live checks cover the Details sidebar, List/Grid/Column canvases, Move Conflict, Empty Trash and a tooltip. Their panel/input/sidebar/button colors match the distinct fixture; cancel keeps both conflicting files and private trash. Open With no longer has an input-colored heading band; fresh running-dialog panel pixels match. The Windows-only graphics compatibility notice uses the same dialog heading pattern and is covered by the five-dialog rendering regression; its startup predicate requires Windows, so Linux AppImage QA cannot trigger that notice. Receipt: additional-consumers-running-check.json. Fresh bundled-theme captures after accent refinements and exact-package acceptance remain pending.

## Final shared-widget review

Filled action buttons retain their selected background beneath hover and pressed overlays. Context-menu action text uses Button text; inactive items remain unfilled and gain the same shaped feedback on interaction. Single-line fields have one shared renderer: raised fill, surface corners, and an Accent focus outline independent of primary/selected text ink. Active/saved theme names and editor section headings explicitly use Heading text. Color rows share a fixed label width, including Button background and Active & focus accent.

Development running-interface evidence: `live-widget-role-refinements-running-check.json` records normal, hovered and pressed button pixels, menu text/feedback, input focus pixels, and an unchanged browsing canvas. Draft cancellation preserves saved configuration. `aligned-color-controls-current-running.png` records the aligned editor. The final 100% fourteen-theme matrix was reviewed before these widget refinements; exact-package native-scale checks must supersede it.
